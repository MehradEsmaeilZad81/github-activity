# GitHub Activity CLI

A simple **command-line tool** built in **Go** that fetches and displays the recent public activity of a GitHub user.

> 🧭 This project is based on the [GitHub User Activity project on roadmap.sh](https://roadmap.sh/projects/github-user-activity).

---

## 📖 Overview

This CLI tool takes a GitHub username as input, fetches the user’s **recent public events** from the [GitHub API](https://api.github.com), and prints them in a clean, human-readable format in your terminal.
